# 재테크 계산기 (연봉 실수령액 · 미국주식 배당 복리)

세금과 4대보험을 뺀 **진짜 월급**과, 배당소득세를 뺀 **진짜 배당금**을 한 화면에서 계산하는 정적 웹앱입니다.

- 빌드 도구·외부 라이브러리·폰트·이미지 의존성 **없음** (파일 4개, 인터넷 없이도 동작)
- 모바일 세로 화면 우선 설계, PC에서는 가운데 정렬로 동일하게 동작
- 결과는 입력 즉시 다시 계산되며, 배당 계산기는 연도별 차트를 함께 그립니다

## 기능

### 1. 2026 연봉 실수령액 계산기
- 연봉(만원)과 부양가족 수를 넣으면 월 실수령액·연 실수령액·월 공제 합계·실효세율을 계산합니다.
- 근로자 부담 4대보험: 국민연금(기준소득월액 상·하한 적용), 건강보험, 장기요양보험, 고용보험
- 근로소득세: 근로소득공제 → 기본공제 → 국민연금·건강보험료 공제 → 기본세율 8구간 → 근로소득세액공제 → 표준세액공제, 지방소득세 10%
- 공제 항목별 금액과 소득세 계산 과정을 표로 보여 주고, 연봉별 월 실수령액 비교표를 함께 제공합니다.

### 2. 미국주식 배당금 & 복리 계산기
- 초기 투자금, 월 적립금, 연 배당률, 연 주가상승률, 투자 기간, 환율을 입력합니다.
- 배당금에서 배당소득세 15.4%를 뺀 **세후 월·연 배당금**과 최종 평가금액, 총 수익률을 계산합니다.
- 막대(평가금액)·꺾은선(세후 연 배당금) 이중 축 차트와 연도별 상세 표를 제공합니다.
- 배당금 재투자(복리) 여부를 선택할 수 있습니다.

```
├── app.js       화면 제어, 차트 렌더링(Canvas)

```

## 계산 기준

| 항목 | 값 | 적용 시점 |
|---|---|---|
| 국민연금 (근로자) | 4.75% | 2026년 |
| 국민연금 기준소득월액 | 410,000 ~ 6,590,000원 | 2026.7 ~ 2027.6 |
| 건강보험 (근로자) | 3.595% | 2026년 |
| 장기요양보험 | 건강보험료의 13.14% | 2026년 |
| 고용보험 (실업급여분) | 0.9% | 2026년 |
| 지방소득세 | 소득세의 10% | 현행 |
| 배당소득 부담률 | 15.4% | 현행 |
| 근로소득공제 한도 | 2,000만원 | 현행 |

- 세율·보험료율은 모두 `calc.js` 상단 `RATES`, `TAX_BRACKETS`에 모아 두었습니다. 제도가 바뀌면 이 값만 고치면 됩니다.
- 보험료는 10원 미만 절사, 세금은 월 단위로 나눠 10원 미만 절사합니다.
- 계산 결과는 **참고용**이며, 실제 급여명세서·연말정산 금액은 비과세 수당, 상여 지급 시기, 개인별 공제·세액공제에 따라 달라집니다.

## 광고 슬롯

`index.html`의 `#adTop`(상단), `#adBottom`(하단) 안쪽 주석 사이에 애드센스 또는 애드핏 코드를 붙여넣으면 됩니다.
광고 코드가 없을 때는 점선 자리 표시자가 그대로 보입니다.

## 배포 (GitHub Pages)

1. 이 폴더의 파일을 저장소 루트(또는 `docs/`)에 올립니다.
2. 저장소 **Settings → Pages → Branch**에서 `main`(또는 `docs/`)을 선택합니다.
3. `https://<아이디>.github.io/<저장소>/` 로 열립니다.
4. 배포 후 `index.html`의 `og:image`, `og:url`을 배포 주소의 **절대 URL**로 바꾸면 SNS 공유 미리보기가 정확해집니다.
